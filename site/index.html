In the game

What you need

Four things, then five steps in Terminal.

  • A Mac with M1 or later. Tested on an M4 Max. macOS 26.4 or later works best.
  • Your original Airfix Dogfighter CD, and a CD drive to copy it. A copy you made earlier also works.
  • About 6.2 GB of free disk space: about 5 GB for the game (about 3 GB on macOS older than 26.4) and about 1.2 GB for the sharper textures.
  • An internet connection while you install, and some time: setup takes a few minutes, and the sharper textures took about eleven on an M4 Max.

About your disc

  • The original CD and a CD drive.
  • A BIN/CUE copy of the whole disc.
  • An ISO file: it has no music.

No disc? This project can't give you the game.

Got all four? Start installing

Install in five steps copy, paste, Return

Open Terminal from Applications > Utilities > Terminal. Paste each command, press Return, and wait until it is finished. The README has every detail.

Frame A has eight parts.

  1. 1 Install Apple's command line tools

    xcode-select --install

    You'll see: A window opens. Click Install and wait.

  2. 2 Install Rosetta 2, only on macOS older than 26.4

    softwareupdate --install-rosetta --agree-to-license

    Skip it: On macOS 26.4 or later you can skip this. With Rosetta installed, the game has a backup: if it does not start on Mach9, it starts on the other Wine.

  3. 3 Get this project

    git clone https://github.com/natemate90/dogfighter.git && cd dogfighter

    Then: Run all later commands in this folder. In a new Terminal window, type cd dogfighter again first.

  4. 4 Copy your game disc to a file

    You need a CD drive and the free tool cdrdao. Install it with Homebrew, a free installer for tools like this:

    brew install cdrdao

    Put the disc in the drive and run:

    cdrdao read-cd --read-raw --datafile Dogfighter.bin --driver generic-mmc:0x20000 Dogfighter.toc

    You'll see: Dogfighter.bin in the folder.

    Other copies: Any program that copies the whole disc to one BIN/CUE pair also works: use the .bin file. An .iso file does not work: it has no music. If the .bin is somewhere else, give its place to setup: ./setup.sh path/to/Dogfighter.bin.

  5. 5 Run setup

    ./setup.sh

    Time: A few minutes. One run on an M4 Max took about eleven minutes.

    What it does: It downloads what it needs and checks each download. It copies the game and the music from your disc file. Last, it makes sharper textures for the game.

    You'll see: Setup is done. Start the game with ./dogfighter, or double-click Dogfighter.app.

    Language: This installs the game in English. For another language, add it at the end: --language=French, --language=German or --language=Italian.

    If it fails: Setup says what went wrong. Fix that and run ./setup.sh again. Finished steps are skipped. If it says a tool is missing, it names the tool, and in most cases the command that installs it.

  6. ✓ Then fly

    ./dogfighter

    First start: about a minute longer. It prepares Wine for the game. The very first start shows the game's setup window: click OK.

    Without Terminal: double-click Dogfighter.app in the folder. You can drag it to Applications or the Dock.

    Mouse: Ctrl+Option frees the mouse. Click in the picture to give it back.

    If something goes wrong: run ./dogfighter --doctor. It checks the install and prints a fix for each problem.

    Cleared for take-off

Questions

Do I need the original CD?

Yes. Setup copies the game and its music from your own disc, so you don't need it while you play. A BIN/CUE copy of the whole disc also works, but an .iso does not, because it has no music.

Does it run on Intel Macs?

No. It needs M1 or later.

Is the game included, and is this official?

No, this project holds only the tools that set the game up. It is for personal use with a disc you own. It is unofficial and not affiliated with Unique Development Studios, Paradox Entertainment or Hornby.

How long does setup take?

A few minutes. It also makes the sharper textures on your Mac: one run on an M4 Max took about eleven minutes. The sharper intro videos are optional and made in a separate step.

Can I play the plain original version?

Yes. Start it with ./dogfighter --original and the game looks as it did in 2000. To leave out only the sharper textures, use ./dogfighter --no-hd-textures.

Where are my saves, and how do I back them up?

Your pilots, levels, photos and stickers are in game/User. Run ./dogfighter --backup to write a dated zip file to the backups folder. To put the newest one back, quit the game and run ./dogfighter --restore.

Does a controller work?

Xbox, PlayStation and Nintendo Switch Pro controllers, and USB or Bluetooth joysticks, should work. Nobody has tried a real controller yet. Connect it before you start, and the launcher turns on Joystick in the game's Options.

Can I play with friends?

Yes, over the network. Tailscale, a free app, is the easiest way and needs no router settings. Without it, the host forwards UDP port 19400 to their Mac in the router's settings.

Is it safe?

Setup checks every download before it uses it. The sharper textures are made on your Mac from your own game files, and nothing is uploaded. Your game files are never changed.

Something broke. What now?

Run ./dogfighter --doctor. It checks the installation and prints a fix for each problem. When you ask for help, include the log file from the logs folder. Still stuck? Send a message.
