Before you start

  • A Mac with Apple Silicon

    An M1 or any later chip.

  • macOS 26.4 or later works best

    It runs Mach9, a Wine made for Apple Silicon: about 100 frames a second in flight on the test Mac. Older macOS uses Rosetta 2 and gets about 30.

  • Your own game disc

    The original CD and a CD drive to copy it. A full BIN copy you made earlier also works. An ISO does not: it has no music.

  • About 6 GB of free space

    For the game and its sharper textures, and an internet connection while you install.

Assembly

Three steps in Terminal. The README has every detail, and what to do when a step stops.

  1. 1

    Copy your disc to a file

    Install cdrdao with Homebrew, put the disc in the drive and copy it to Dogfighter.bin.

    brew install cdrdao
cdrdao read-cd --read-raw --datafile Dogfighter.bin --driver generic-mmc:0x20000 Dogfighter.toc
  2. 2

    Get the project and run setup

    Setup downloads what it needs and checks each download. It copies the game and its music from your disc file, then makes the sharper textures. The second line installs Rosetta 2. Skip it on macOS 26.4 or later.

    xcode-select --install
softwareupdate --install-rosetta --agree-to-license
git clone https://github.com/natemate90/dogfighter.git
cd dogfighter
./setup.sh ../Dogfighter.bin
  3. 3

    Play

    Start the game, or double-click Dogfighter.app. It opens in a normal Mac window you can resize. Ctrl+Option frees the mouse.

    ./dogfighter

What the kit adds

The game as it was in 2000, with these on top. --original keeps the game's own picture: 16-bit colour, the normal draw distance, its own resolution and textures.

A Speed
On macOS 26.4 or later, about 100 frames a second in flight. Missions load in 2 to 5 seconds. Measured on an M4 Max.
B A sharper picture
The 3D world uses every pixel of a Retina screen. Textures get twice the pixels, menus and loading screens four times. Your Mac makes them from your own disc. The plane paintings and the kit boxes and paint tins on the main menu are drawn from photos of real model-kit boxes and a paint tin, which setup downloads.
C Clear letters
The pilot screens, the mission book and the briefing are redrawn from matching fonts, so text stays crisp in a big window.
D Controllers
Xbox, PlayStation and Switch Pro controllers and USB joysticks should work. Nobody has tried a real one yet.
E Music and saves
The music comes from the disc's audio tracks. One command backs up your pilots and saves.
F Friends
Fly against each other over the internet. Tailscale makes it easiest: no router settings.

Choose a finish

Add one of these after ./dogfighter. The README lists them all.

  • ./dogfighter

    Nothing added: the best picture. This is the default.

  • --original

    The game exactly as it looked in 2000.

  • --no-hd-textures

    Every Retina pixel, with the game's own textures.

  • --mute

    No sound, this time only.

  • --doctor

    Checks the install and prints a fix for each problem.

  • --backup

    Puts your pilots and settings in a dated zip file.
